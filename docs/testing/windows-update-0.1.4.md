## 修复及离线检查

- 实际单行 Cookie 中的一条无名称值被旧校验器误拒绝。现保留原样，拒绝控制字符、错误名称和响应属性；无名称值不伪装成登录字段。测试全部使用合成凭据。
- 采集请求只发送来自已导入 Cookie 的真实 UIFID，403 网关响应仅转为固定分类，不保存原文，不生成占位安全头。
- 后端 118 项测试、前端构建、cargo check --locked、Rust release、PyInstaller 和 NSIS 构建通过。
- 打包空配置六项检查、打包及安装后端的认证、合成媒体、Cookie 加密/重启/清除检查通过。发行版与安装版各两次桌面隔离生命周期检查通过；相关 JSON 文件均以 0.1.4 标记。
- 覆盖安装退出码 0，原任务、模型配置和套餐授权保留，安装后端与构建文件相同。安装包 302168570 字节，SHA256 见 [安装清单](windows-installer-0.1.4.json)。
- 用户手动提供的 70 项真实 Cookie 在更新后加密保存，解密往返一致；本任务临时明文文件已删除。

## 真实访问结果

- [源码真实检测](share-links-cookie-www-0.1.4.json)和[安装后端真实检测](installed-share-links-cookie-0.1.4.json)均使用 www.douyin.com 登录状态与真实客户端标识。两条原始分享短链解析通过，作品读取仍 HTTP 403 / gateway_signature_missing；作者数据、第二页及实际下载均未通过。
- 正常浏览器访问原作品，标题、作者“开心锤锤”可见，视频进度达到 68.036448 / 150.166 秒，readyState=4、paused=false。浏览器会话未导入用户 Cookie；这是网页播放检查。
- 页面采用 blob 媒体流。浏览器导出尝试失败，未得到可由 FFprobe 校验的媒体文件；网页播放成功不等于软件采集通过。

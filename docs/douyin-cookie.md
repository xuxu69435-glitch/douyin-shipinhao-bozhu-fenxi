# 获取并导入抖音 Cookie

适用于在自己的浏览器中已登录抖音网页版，并有权访问待分析视频的用户。Cookie 是登录凭据，只在本机导入，不要发到聊天、Issue 或 Git。无需安装 Cookie 提取插件。

## 从浏览器获取

1. 用 Edge 或 Chrome 打开 [抖音网页版](https://www.douyin.com/)，登录自己的账号。打开目标博主主页或作品，先确认浏览器能正常显示、播放。
2. 按 **F12** 打开开发者工具，切换至 **Network / 网络**。保持开发者工具打开，刷新抖音页面；若没有作品请求，可播放作品或向下滚动主页。
3. 选择 **Fetch/XHR**，点击作品请求，例如 `feed`，或筛选 `aweme` / `post`。**Name 列通常只显示请求名称，不会直接显示域名**；点击后在 **Headers / 标头 → General / 常规 → Request URL / 请求网址** 中，确认地址以 `https://www.douyin.com/` 开头。不要选视频 CDN、图片或广告请求。
4. 点击该请求 → **Headers / 标头** → **Request Headers / 请求标头**，找到 **Cookie**。
5. 复制 Cookie 的**值**。正确内容通常是 `名称=值; 名称2=值2` 这样的单行文本。不要复制 Response Headers 中的 `Set-Cookie`，不要复制整段 cURL、JSON 或全部请求标头。软件也接受以 `Cookie:` 开头的单行文本。

如果看不到 Cookie，先确认所选请求属于 `www.douyin.com` 且是在登录后刷新产生的。不要从其他网站取登录状态，也不要用 `document.cookie` 代替完整请求头；它可能缺少 HttpOnly 登录字段。

遇到“HTTP 422”表示本机导入内容未通过校验，并非抖音返回的登录失败。请复制 **Request Headers** 中 Cookie 行的完整值，避免从 **Cookies** 表格逐格复制。软件保留单行值中的引号、JSON 内容、等号和同名 Cookie；错误提示只指出出错的项数，不显示凭据。修复前的 0.1.3 构建可能误拒绝 JSON 内容或丢失后续字段，需更新安装程序后重新导入。

## 导入软件

1. 打开 **模型与采集设置 → 抖音采集设置**，勾选 **启用真实抖音采集**，点击 **保存配置**。
2. 展开采集设置，在 **抖音登录状态** 中粘贴上一步复制的值，点击 **加密保存登录状态**。无需新建文本文件。
3. 成功后输入框清空，只显示已保存项数及是否发现常见登录标记；不会回显 Cookie 内容。
4. 回到任务中心，粘贴完整分享文本或链接，点击 **检测此链接的采集能力（不调用模型）**。先分别检测作品和主页，不需要消耗模型额度。

已有 UTF-8 单行 Cookie 文本文件时，可以在“已有 Cookie 文本文件？”中填写路径；支持 UTF-8 BOM。加密导入的登录状态优先于旧文件。若希望改用旧文件，先清除已保存状态。此清除操作不删除自行提供的原文件。

## 如何验收

“保存成功”只表示格式及本机加密通过；“包含登录标记”也不证明登录仍有效。实际结果以采集检测为准：

| 项目 | 通过证据 |
| --- | --- |
| 链接 | 分享地址解析为正确的作品/主页 |
| 作者 | 从真实作品数据取得并校验作者 ID，不能只从网址推断 |
| 作品 | 取得真实列表并按作品 ID 去重 |
| 第二页 | 实际翻页且出现第一页没有的作品 ID；单视频检测不适用 |
| 媒体 | 实际下载文件含视频流并通过 FFprobe，不能只检查一个 URL |

可以导出检测 JSON。该报告不包含 Cookie 或带签名的媒体地址，适合用于定位失败阶段。

## 失效及限制

- Cookie 过期、退出登录或平台更新后，重新按上述步骤导入。每个人使用自己的登录状态，不共享安装者的 Cookie；加密文件绑定本机 Windows 用户，复制给另一人不能代替登录。
- HTTP 401/403/429 时先确认浏览器对同一链接仍可访问。更新 Cookie 后仍失败，可能是平台接口、网关或访问频率限制；不要把这种结果标成通过，也不要连续无限重试。
- 没有 Cookie 时可以匿名检测，也可独立导入本地视频分析。本地视频通过不替代抖音采集验收。

抖音开放平台的 `video.list` 是另一种需要应用权限及用户授权的接口，不能用普通网页 Cookie 代替其 access_token，也不能假定它能读取任意博主。参见[官方授权账号视频列表](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/search-video/account-video-list)。
